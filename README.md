# 현주에듀랩 홈페이지

학교·교육기관·기업을 위한 안전·환경·AI 교육 브랜드 홈페이지다.

## 설치와 실행

프로젝트 폴더에서 실행한다. 버전 기준은 package-lock.json이다.

```bash
npm ci
npm run dev
```

개발 서버 주소는 http://localhost:3000 이다.

전체 검증은 린트, 프로덕션 빌드, 타입 검사를 순서대로 실행한다. 빌드 단계에서 Next.js의 타입 파일을 생성한 뒤 별도 타입 검사를 수행한다.

```bash
npm run verify
npm start
```

- 검증한 로컬 환경은 Windows, Node.js 24.21.0, npm 11.19.0이다.
- 기존 Vercel 프로젝트의 Node 설정은 26.x다. 운영 환경의 검증은 Vercel 빌드 결과를 별도로 확인한다.
- Next.js는 16.4.5, React는 19.3.1, Tailwind CSS는 4.3.4, TypeScript는 5.9.3으로 잠겨 있다.
- 의존성을 복구할 때는 잠금 파일 기반의 깨끗한 작업 폴더에서 npm ci를 사용한다. package.json의 범위만으로 설치한 버전은 잠금 파일과 다를 수 있다.
- OneDrive의 생성 파일 잠금이나 권한 오류가 발생하면 별도 검증 폴더에 추적 소스를 복사해 실행한다. 기존 .next 또는 node_modules의 불명확한 링크 대상을 삭제·이동하지 않는다.

## 공개 페이지와 보존 기준

| 주소 | 유지할 기능 |
|---|---|
| / | 현장 사진 2장, 강의 문의, 분야 앵커와 강사 소개·자료실 연결 |
| /about | 강사 소개에서 교육 프로그램 이동 |
| /education | 분야 4종과 기존 앵커, 문의 화면 연결 |
| /digital | 서비스 3종과 문의 화면 연결 |
| /portfolio | 준비 사례와 관련 교육·자료실 연결 |
| /insights | 이용 안내와 문의·자료 목록 연결 |
| /materials | 자료 2종 검색, 결과 건수·빈 결과·초기화 |
| /materials/carbon-neutrality | 상세 제목·학습 목표·활동 예시와 목록 복귀 |
| /materials/traffic-safety | 상세 제목·학습 목표·활동 예시와 목록 복귀 |
| /contact | 입력 형식 검증과 입력 확인용 상태 안내 |
| 존재하지 않는 주소 | HTTP 404와 홈·자료실 복귀 |

교육 목록의 industrial-safety, school-safety, environment, ai 앵커와 자료 slug 2개는 기존 링크 호환 기준이다.

## 기능 검수

| 항목 | 확인할 동작 |
|---|---|
| 모바일 메뉴 | Enter로 열기, Tab 탐색, Esc 닫기·버튼 포커스 복귀, 이탈·이동 시 닫기 |
| 본문 바로가기 | 첫 Tab에서 링크 표시, Enter로 main에 포커스 |
| 반응형 | 320·360·390·768·1280px에서 가로 넘침과 콘텐츠 가림 확인 |
| 사진 | 대표·보조 사진 로딩, 대체텍스트, 문의 링크 |
| 자료 검색 | 한글·공백·문장부호·복수 키워드, 빈 결과, 초기화 후 포커스 |
| 자료 상세 | 검색 결과에서 이동, 직접 주소·새로고침·목록 복귀, 잘못된 slug의 404 |
| 문의 | 필수값·공백·이메일·확인 체크, 입력 수정 시 상태 초기화 |
| 문의 확인 | 형식 확인 결과를 표시하고 실제 접수 완료로 표시하지 않음. 확인 시 전송·저장 요청 없음 |

현재 문의는 브라우저 입력 확인용이며 실제 접수·알림·관리자·자료 원본 다운로드는 후속 개발 범위다.

## 고도화 1일차 검증 결과

2026년 11월 19일, 기준 커밋 a6fa7ca의 추적 소스에 이 문서와 verify 명령을 적용해 별도 신규 폴더에서 검증했다.

| 검사 | 결과 |
|---|---|
| npm ci | 새 폴더에서 성공, 주요 설치 버전과 잠금 파일 일치 |
| npm run verify | 린트·프로덕션 빌드·별도 타입 검사 통과 |
| 공개 페이지 10개·404·본문 바로가기·메뉴 | 320·360·390·768·1280px Chrome 검수 통과 |
| 문의 입력·확인·수정 | 360·390·768·1280px 검수 통과, 확인 시 네트워크 요청 없음 |
| 자료 검색·초기화·빈 결과 | 360·390·768·1280px 검수 통과 |
| 자료 상세·새로고침·목록 복귀·잘못된 slug | 360·390·768·1280px 검수 통과 |
| 사진 2장·가로 넘침·문의 이동 | 360·390·768·1280px 검수 통과 |

검증 폴더는 OneDrive 바깥의 별도 작업 폴더다. 기존 OneDrive 작업 폴더의 설치 버전 차이·파일 잠금이 해소됐다고 판단한 결과는 아니다. Safari·실제 모바일 기기·스크린리더 적합성은 이번 검수 범위 밖이다.

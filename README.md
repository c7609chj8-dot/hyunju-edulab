# 현주에듀랩 홈페이지

학교·교육기관·기업을 위한 안전·환경·AI 교육 브랜드 홈페이지다.

## 설치와 실행

프로젝트 폴더에서 실행한다. 버전 기준은 package-lock.json이다.

```bash
npm ci
npm run dev
```

개발 서버 주소는 http://localhost:3000 이다.

전체 검증은 린트, 프로덕션 빌드, 타입 검사를 순서대로 실행한다. 빌드 단계에서 Next.js의 타입 파일을 생성한 뒤 별도 타입 검사를 수행한다.

```bash
npm run verify
npm start
```

- 검증한 로컬 환경은 Windows, Node.js 24.21.0, npm 11.19.0이다.
- 기존 Vercel 프로젝트의 Node 설정은 26.x다. 운영 환경의 검증은 Vercel 빌드 결과를 별도로 확인한다.
- Next.js는 16.4.5, React는 19.3.1, Tailwind CSS는 4.3.4, TypeScript는 5.9.3으로 잠겨 있다.
- 의존성을 복구할 때는 잠금 파일 기반의 깨끗한 작업 폴더에서 npm ci를 사용한다. package.json의 범위만으로 설치한 버전은 잠금 파일과 다를 수 있다.
- OneDrive의 생성 파일 잠금이나 권한 오류가 발생하면 별도 검증 폴더에 추적 소스를 복사해 실행한다. 기존 .next 또는 node_modules의 불명확한 링크 대상을 삭제·이동하지 않는다.

## 고도화 2일차 검증 결과

- 메뉴 목록을 app/site-links.ts에서 공통 관리하고 헤더와 하단에서 같은 경로를 사용한다.
- 헤더는 현재 페이지와 자료 상세의 상위 영역을 색상·밑줄·aria-current로 표시한다.
- 교육자료 메뉴는 교육자료실, 문의 메뉴는 강의 의뢰로 표기한다. 강의 의뢰는 강조 버튼으로 표시한다.
- 72rem 미만에서는 접이식 메뉴를 사용한다. 사진·카드 레이아웃의 기존 반응형 기준은 유지한다.
- 잠금 파일 기준 검증 환경에서 npm run verify를 통과했다.
- Chrome의 320·390·768·1024·1280px에서 헤더·하단 링크 7개, 상세 상위 메뉴 표시, 본문 바로가기, Tab·Esc·포커스 이탈·외부 클릭·화면 폭 전환을 확인했다.
- 모바일·데스크톱의 헤더와 하단 디자인을 캡처해 확인했다.

## 고도화 7일차 검증 결과

- 교육 분야 4종의 상세 페이지를 추가하고 목록의 기존 앵커는 보존했다. 상세·메타·정적 경로는 app/programs.ts를 기준으로 생성한다.
- 상세에는 대상·학습 목표·교육 흐름 예시·참여 활동·준비사항·FAQ·관련 정보를 표시한다. 시간·차시·인원·비용·제공 자료는 미확정이므로 사전 협의로 안내한다.
- 상세의 의뢰 링크는 /contact?program=과정slug로 연결한다. 공개 과정 식별자만 URL에 사용하고 개인 입력값은 넣지 않는다.
- 문의 화면은 허용된 단일 과정 값만 관심 교육 분야에 반영한다. 알 수 없는 값·중복 값은 선택하지 않는다. 과정 변경 시 확인 상태를 초기화한다.
- 관심 교육 분야는 선택 항목이고 기존 필수 입력 검증을 유지한다. 실제 접수·전송·저장은 구현하지 않았다.
- 문의 화면은 검색 매개변수 검증을 위해 요청 시 서버 렌더링하며, 교육 상세 4개는 정적으로 생성한다. 신규 외부 서비스·환경변수는 필요하지 않다.
- npm run verify의 린트·프로덕션 빌드·타입 검사를 통과했다.
- Chrome 320·390·768·1024·1280px에서 상세 4개·직접 주소·새로고침·FAQ 키보드 조작·관련 링크·기존 메인 앵커·과정 자동 선택·잘못된 쿼리·404·가로 넘침과 브라우저 오류를 확인했다.
- 예시 입력 확인 시 문의 데이터 전송 요청·입력값의 URL 노출이 없고 실제 미접수 안내를 유지하는 것을 확인했다. Next.js의 페이지 사전 로딩 GET 요청은 문의 전송과 구분했다.
- 모바일·PC 캡처를 확인했다. 실제 모바일 기기·Safari·스크린리더 검수는 미실시다.
